# AutoDKP

Локальный Telegram-бот для подготовки печатного договора купли-продажи автомобиля на основе исходного шаблона Авто.ру.

## Текущий статус

Реализованы основные этапы подготовки ДКП:

- безопасный каркас приложения;
- доменные модели без постоянного хранения персональных данных;
- координатный PDF-рендерер;
- синтетический демонстрационный договор;
- автоматические проверки структуры PDF и защищённых областей подписей;
- пошаговый ручной ввод всех данных сделки с проверкой каждого ответа;
- проверка, редактирование и генерация PDF прямо из Telegram;
- заполнение по фото СТС, ПТС и паспортов через отключённый по умолчанию OpenAI Vision provider;
- очистка EXIF/GPS, проверка JPEG/PNG, явное подтверждение каждого пакета распознанных данных;
- временный изолированный черновик в памяти и очистка по `/cancel`.

Для реального распознавания нужны `OCR_PROVIDER=openai` и `OPENAI_API_KEY`.
Без них бот не примет фото и предложит ручной сценарий.
Ключ можно добавить без вывода на экран командой
`PYTHONPATH=src .venv/bin/python -m autodkp.cli configure-ocr`.

## Быстрый запуск

```bash
uv sync --no-editable
cp .env.example .env
.venv/bin/autodkp demo-pdf
.venv/bin/pytest
```

Для запуска Telegram-бота укажите токен и разрешённые числовые Telegram ID:

```bash
PYTHONPATH=src .venv/bin/python -m autodkp.cli pair-bot
PYTHONPATH=src .venv/bin/python -m autodkp.cli bot
```

Команда `pair-bot` вводит токен скрыто, проверяет его у Telegram и показывает
одноразовую команду `/pair`. После получения команды от владельца бот создаёт
`.env` с правами `0600` и разрешает доступ только этому Telegram ID. Код действует
не более пяти минут. Альтернативная команда `configure-bot` позволяет ввести
известный числовой Telegram ID вручную. Обе команды отказываются перезаписывать
существующую конфигурацию.

Если токен попал в переписку или лог, сначала отзовите его через BotFather, затем
безопасно замените только токен, сохранив привязанный Telegram ID:

```bash
PYTHONPATH=src .venv/bin/python -m autodkp.cli rotate-bot-token
```

`--no-editable` используется из-за известной проблемы editable-установки в пути,
содержащем пробелы и кириллицу.

## Приватность MVP

Персональные данные сделки не должны попадать в SQLite и логи. Черновик хранится только в памяти процесса, а документы — во временном каталоге сделки. После перезапуска незавершённый черновик не восстанавливается.

Важно: локальное удаление не удаляет сообщения и файлы из инфраструктуры Telegram или с устройств пользователя.
Облачный OCR включается только отдельной настройкой и после согласия в Telegram.

## Серверный запуск

Проект подготовлен к запуску одним Docker-контейнером:

```bash
docker compose up --build -d
```

Токен и allowlist передаются только через переменные окружения. Контейнер
запускается без root-доступа, использует read-only filesystem и временный `/tmp`.
Инструкция для Timeweb Cloud находится в `deploy/timeweb.md`.
