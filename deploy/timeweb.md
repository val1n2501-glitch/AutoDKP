# Развёртывание AutoDKP в Timeweb Cloud

Рекомендуемый режим — один контейнер и один процесс long polling. Несколько
реплик запускать нельзя: черновики хранятся в памяти, а Telegram принимает один
polling consumer для токена.

## Секреты приложения

Задайте в панели сервиса, не добавляя значения в Git:

- `TELEGRAM_BOT_TOKEN` — действующий токен BotFather;
- `ALLOWED_TELEGRAM_IDS` — числовой Telegram ID владельца;
- `DEAL_TTL_MINUTES=60`;
- `LOG_LEVEL=INFO`.

Пути шаблона и шрифта уже заданы в `Dockerfile` и `docker-compose.yml`.

## App Platform

1. Подключите Git-репозиторий в разделе App Platform.
2. Выберите сборку из `docker-compose.yml` в корне репозитория.
3. Добавьте секреты из списка выше.
4. Выберите одну реплику и включите автодеплой основной ветки.
5. Запустите деплой и дождитесь строки `Run polling for bot` в журнале.

Контейнер работает с непривилегированным пользователем, с read-only root
filesystem и отдельным временным `/tmp`. PDF и введённые персональные данные не
сохраняются между перезапусками.

## Проверка после запуска

1. Откройте `@AutoDKP_RU_Bot` и отправьте `/start`.
2. Убедитесь, что появилась кнопка ручного создания ДКП.
3. Проверьте `/cancel` после начала анкеты.
4. Проверьте полный тестовый договор и скачайте PDF.
